# M1-T08 — ROM repo probe, pinning & preprocessor harness

## Goal

Implement `src/npc_planner/ingest/rom_probe.py` and `scripts/preprocess_rom.py` to (a) locate a pokeemerald-expansion working tree, (b) detect its layout version and record git pins, and (c) run the C preprocessor over the battle-data headers, emitting `.i` files into `data/raw/romdata/`.

This task produces **no parsed data**. Its only output is expanded translation units plus a manifest. Parsing is M1-T09 onward.

```python
# src/npc_planner/ingest/rom_probe.py
from dataclasses import dataclass
from pathlib import Path

class RomLayoutUnknownError(RuntimeError):
    """Raised when no known expansion layout matches the repo. Error code E_ROM_LAYOUT_UNKNOWN."""

@dataclass(frozen=True)
class RomLayout:
    species_info: list[Path]
    moves_info: Path
    abilities: Path
    types_info: Path
    items: Path
    level_up_learnsets: Path
    teachable_learnsets: Path
    egg_moves: Path
    wild_encounters_json: Path
    trainers: Path
    trainers_format: str
    config_headers: list[Path]
    layout_id: str

@dataclass(frozen=True)
class RomPin:
    repo_path: Path
    hack_sha: str
    hack_dirty: bool
    upstream_remote: str | None
    upstream_sha: str | None
    expansion_version: str | None

def probe_layout(repo_path: Path) -> RomLayout:
    """Detect which expansion layout this repo uses.

    Raises RomLayoutUnknownError listing which expected paths were missing.
    Never guesses: if species data cannot be located, it raises.
    """

def read_pin(repo_path: Path) -> RomPin:
    """Read git SHAs and dirty state via subprocess git calls."""
```

## Must-pass tests

1. `probe_layout()` against `tests/fixtures/fake_rom/` (1.9+ style tree) returns `layout_id == "expansion_1_9_plus"` and `trainers_format == "party"`.
2. `probe_layout()` against a tree missing `species_info` raises `RomLayoutUnknownError`, and the message names the missing path.
3. `read_pin()` on a fixture git repo with an uncommitted change returns `hack_dirty is True`.
4. `preprocess_rom.py --repo tests/fixtures/fake_rom --output <tmp>` produces at least one `.i` file plus `ROM_MANIFEST.json` containing a sha256 for every `.i` emitted.
5. Preprocessing honours conditionals: the fake repo's `species_info.h` contains a species guarded by `#if P_GEN_9_POKEMON == TRUE` with the config set to `FALSE`; the guarded species **must not** appear in the `.i` output.
6. No network access — enforced by a `monkeypatch` fixture that makes `socket.socket.connect` and `socket.create_connection` raise.

## Out of scope — do NOT implement

- Parsing `.i` contents into records — that is **M1-T09**
- Writing to any SQLite table — that is **M1-T11 onward**
