# M1-T08 — Standalone network-isolated baseline dump fetcher

## Goal

Implement `scripts/fetch_baseline.py` to populate baseline raw dumps in `data/raw/` (or a custom output directory). Supports `--from <dir>` to copy raw dumps locally (e.g. from test fixtures) without network access.

## Files you may create or modify

- `scripts/fetch_baseline.py`
- `tests/unit/test_fetch_baseline.py`

## Files you may read but NOT modify

- `src/npc_planner/config.py`
- `tests/fixtures/m1_tiny/*`

## Files you may NOT touch

Everything else. Verify with `git diff --name-only` before committing.

## Contract

```python
# scripts/fetch_baseline.py
# Executable script with chmod +x
# Usage:
#   python3 scripts/fetch_baseline.py --from tests/fixtures/m1_tiny --output data/raw/
#   python3 scripts/fetch_baseline.py --output data/raw/
```

## Must-pass tests

1. Running `fetch_baseline.py --from tests/fixtures/m1_tiny --output <tmp_dir>` populates `<tmp_dir>` with `meta.json`, `species.json`, `forms.json`, `moves.json`, `abilities.json`, `type_matchups.json` without making network calls (asserted via socket monkeypatching).
2. Target directory is created automatically if it does not exist.
3. Script handles `--help` gracefully with exit code 0.

## Out of scope — do NOT implement

- Loading raw dumps into SQLite `stg_*` — that is **M1-T09**

## Acceptance command

```bash
make check && TMP_OUT=$(mktemp -d) && python3 scripts/fetch_baseline.py --from tests/fixtures/m1_tiny --output "$TMP_OUT" && python3 -c "
from pathlib import Path
import sys
p = Path(sys.argv[1])
files = list(p.glob('*.json'))
print(len(files))
" "$TMP_OUT" && rm -rf "$TMP_OUT"
# expected output: 6
```
