## Must-pass tests

1. `load_baseline_dumps(conn, "tests/fixtures/m1_tiny")` executes without error against initialized database.
2. `build_info` table contains record from `meta.json`.
3. `stg_species`, `stg_forms`, `stg_moves`, `stg_abilities`, `stg_type_matchups` are populated with exact row counts matching fixture JSONs.
4. Function is idempotent (running twice on same connection yields identical row counts and does not duplicate rows).
5. Function raises `FileNotFoundError` if `raw_dir` or required JSON file does not exist.
