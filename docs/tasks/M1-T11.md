## Part B - species ingest

### B1. Shape

```python
@dataclass(frozen=True)
class BaseStats:
    hp: int
    attack: int
    defense: int
    sp_attack: int
    sp_defense: int
    speed: int

@dataclass(frozen=True)
class SpeciesRecord:
    rom_id: str                      # "SPECIES_SKARMORY"
    base_stats: BaseStats
    types: tuple[str, ...]           # normalised, 1 or 2 entries
    raw_types: tuple[str, ...]       # exactly as written in the header
    abilities: tuple[str, ...]       # slot order preserved, ABILITY_NONE kept
    hidden_ability: str | None
    source_file: str                 # repo-relative
    source_record: str               # the initializer key, e.g. "SPECIES_SKARMORY"
    unparsed_fields: tuple[str, ...]

class SpeciesParseError(ValueError): ...
```

Two entry points, so the parser is testable without a filesystem:

```python
def parse_species(text: str, source_file: str) -> tuple[SpeciesRecord, ...]: ...
def read_species(layout: RomLayout) -> tuple[SpeciesRecord, ...]: ...
```

Records are returned sorted by `rom_id`. Determinism is not a nice-to-have; the
lockfile hashes this output.

### B2. Nothing is dropped silently

Every key inside a species initializer must end up in exactly one of three
places: mapped to a field, listed in a declared `IGNORED_FIELDS` frozenset, or
recorded in `unparsed_fields`. Anything else is a bug.

```python
def audit_species_coverage(
    records: Sequence[SpeciesRecord],
) -> tuple[str, ...]:
    """Return every initializer key that reached no field, no ignore rule and
    no unparsed_fields entry. Empty means total coverage."""
```

`IGNORED_FIELDS` must be a short, declared, commented list - sprite pointers,
footprint data, cry ids. If it starts growing to silence warnings, the mechanism
has been defeated. A test pins its exact contents.

### B3. Rules that must not be softened

- **Missing base stat is an error**, never a zero. A species with no `baseSpeed`
  is a parse failure, not a species with 0 speed.
- **Missing types is an error** (`E_SPECIES_NO_TYPES`), never an empty tuple.
- **`ABILITY_NONE` is preserved** in the `abilities` tuple. Filtering it out
  shifts every later slot index, and slot index is how the ROM identifies which
  ability a trainer's Pokemon has.
- **Mono-types normalise, but the raw form is kept.** Gen 3 style writes
  `(TYPE_ELECTRIC, TYPE_ELECTRIC)`; the expansion may write one entry. `types`
  holds the deduplicated ordered tuple, `raw_types` holds what was written.
  Both are asserted.
- **Duplicate `SPECIES_` keys are an error**, not last-one-wins.
- **No `eval`, `exec`, `ast.literal_eval` or `compile`.**

### B4. Provenance

This is the first task to emit provenance, so it sets the pattern. Every record
carries `source_type="rom_extract"` and confidence `0.80` (`rom_present` from
the verification-status table), with `source_file` repo-relative and
`source_record` the initializer key. Do not invent a higher confidence because
the parse succeeded - parsing correctly and the ROM behaving as parsed are
different claims.

## Out of scope - with reasons

- **Generation gating.** Whether a species is compiled in depends on
  `#if P_GEN_N_POKEMON` blocks, which needs conditional-compilation awareness
  and belongs on the preprocessed `.i` path, not the raw header. Do **not**
  guess from National Dex ranges. `enabled_generations()` exists but is not
  applied here.
- **Evolutions** - M1-T17. They live in `gSpeciesInfo[].evolutions` but pull in
  a second grammar; record the key in `unparsed_fields` and move on.
- **Learnsets** - M1-T15 and M1-T16.
- **Writing to SQLite** - M1-T23. This task returns dataclasses only.
- **National Dex number.** Only include it if the fixture actually carries it;
  if it does not, say so and leave the field off rather than inferring one.

## Must-pass tests

Against `tests/fixtures/fake_rom`, using the known Skarmory record
(65/80/140/40/70/70, Steel/Flying, hidden Weak Armor):

1. `SPECIES_SKARMORY` is present
2. its stats are hp 65, attack 80, defense 140, sp_attack 40, sp_defense 70,
   speed 70
3. `types == ("TYPE_STEEL", "TYPE_FLYING")`
4. `hidden_ability == "ABILITY_WEAK_ARMOR"`
5. `abilities[0] == "ABILITY_KEEN_EYE"` and slot order is as written
6. `ABILITY_NONE`, if present in any record, survives in `abilities`
7. a synthetic mono-type written twice yields `types` of length 1 and
   `raw_types` of length 2
8. a synthetic record missing `baseSpeed` raises `SpeciesParseError`
9. a synthetic record with no types raises `SpeciesParseError`
10. a synthetic input with two identical `SPECIES_` keys raises
11. every record has six stats, each an `int` in 0..255
12. every entry in `types` starts with `TYPE_`; every ability with `ABILITY_`
13. `audit_species_coverage(records) == ()`
14. coverage returns non-empty for a synthetic record carrying an unknown key
    that is neither mapped nor ignored - **the guard must be able to fail**
15. `IGNORED_FIELDS` has exactly its documented contents
16. two consecutive `read_species` calls compare equal
17. records are sorted by `rom_id`
18. provenance: `source_type` is `rom_extract`, confidence `0.80`,
    `source_file` is repo-relative and does not contain an absolute path
19. `parse_species` works on a string with no filesystem access
20. no forbidden dynamic-evaluation call in the module
