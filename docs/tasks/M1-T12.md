4. **`symbolic_fields: tuple[tuple[str, str], ...]` Data Model:**
   - Replace stringly-typed `unparsed_fields` entries with `symbolic_fields: tuple[tuple[str, str], ...]` (sorted tuple of `(key, symbol)` pairs) on `SpeciesRecord` and `MoveRecord`. Add `@property def symbolic_map(self) -> dict[str, str]`.
   - `symbolic_fields` records ONLY numeric fields (`int | None`) that received an unresolved symbol. Fields declared `str` store their symbol verbatim as the mapped value.
   - Refactor `audit_species_coverage` and `audit_moves_coverage` to union `MAPPED_FIELDS | IGNORED_FIELDS | set(unparsed_fields) | set(symbolic_map.keys())` without string splitting.

5. **Disjoint Field Sets Invariant & `__post_init__` Enforcement:**
   - Enforce invariant `set(unparsed_fields) & set(symbolic_map.keys()) == set()` and sorted key order in `__post_init__` on `SpeciesRecord` and `MoveRecord`.
   - Add unit tests verifying `__post_init__` raises `ValueError` on invariant violation.

6. **Nullable Ints & Nullable Category for Moves:**
   - Type `power`, `accuracy`, `pp`, `priority`, and `category` as `int | None` / `str | None`.
   - Store `None` for numeric fields when raw C value is a symbol, and record `(field_name, symbol_name)` in `symbolic_fields`.
   - `category` is `str | None` (verbatim symbol if present, else `None`).
