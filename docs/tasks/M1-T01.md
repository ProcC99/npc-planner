Create `pyproject.toml`, `src/npc_planner/__init__.py`, and `src/npc_planner/config.py` for project configuration and path resolution.

    exports_dir: Path

    ...

## Must-pass tests

1. `get_settings()` returns valid paths under project root.
2. Custom `root` path overrides defaults cleanly.
3. Package `__version__` string is defined in `src/npc_planner/__init__.py` as `"0.1.0a1"`.
