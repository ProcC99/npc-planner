# M1-T08c - Scope the preprocess preflight; make read_pin git-optional

> **Remediation card.** `M1-T08b` (`0d561ef`) gated `cpp` preprocessing behind *all* hard doctor
> checks, including `is_git_repo`. Because `tests/fixtures/fake_rom/` is not a git repository and
> cannot be one (a nested `.git` cannot be committed), `preprocess_rom.py --repo
> tests/fixtures/fake_rom` now exits 3 unconditionally. That silently contradicts `M1-T08`
> must-pass tests 4 and 5 and the `M1-T08` acceptance command, all of which are marked `done`.
>
> **Depends on:** M1-T00b, M1-T08b.
> **Read `docs/PROTOCOL_AMENDMENT_11.md` before starting.** This is the first task executed under
> the amended protocol: this card is immutable, and acceptance runs from a script file.

## Goal

Split the doctor's hard checks into a **preprocessing** subset and a **pinning** subset. Make
`preprocess_rom.py` require only the preprocessing subset. Make `read_pin()` degrade gracefully
on a non-git tree instead of failing. Replace the vacuous single-resolver guard.

## Contract

### 1. Check subsets become named data

`CHECK_SEVERITY` stays exactly as `M1-T00b` shipped it. Add a second, orthogonal classification
in `src/npc_planner/environment.py`:

```python
# Checks that must pass before it is safe to run `cpp` over a tree.
# Git is deliberately absent: preprocessing reads files, it does not read history.
PREPROCESS_REQUIRED: tuple[str, ...] = (
    "cpp",
    "repo_present",
    "expansion_markers",
)

# Checks that must pass before a build may claim to be reproducibly pinned.
PINNING_REQUIRED: tuple[str, ...] = (
    "repo_present",
    "is_git_repo",
)

def run_checks(
    repo_path: Path,
    names: Sequence[str],
    cpp: str = "cpp",
) -> list[CheckResult]:
    """Run only the named checks, in the order given.

    Raises KeyError if any name is not a key of CHECK_SEVERITY.
    Never raises for check failures; those are returned as CheckResult rows.
    """

def run_all(repo_path: Path, cpp: str = "cpp") -> list[CheckResult]:
    """Equivalent to run_checks(repo_path, tuple(CHECK_SEVERITY), cpp)."""
```

`run_all` must be *implemented in terms of* `run_checks`, not duplicated. Both
`PREPROCESS_REQUIRED` and `PINNING_REQUIRED` must be subsets of `CHECK_SEVERITY`'s keys, and
every member of both must have severity `hard` - a soft check in a required set is a
contradiction and must be caught by a test, not by review.

`doctor.py` is unchanged: it still runs `run_all` and still reports on all six checks. The
subsets narrow what *other callers* demand, not what the doctor reports.

### 2. `read_pin` degrades instead of failing

```python
# src/npc_planner/ingest/rom_probe.py

@dataclass(frozen=True)
class RomPin:
    repo_path: Path
    hack_sha: str | None            # CHANGED: was str
    hack_dirty: bool
    upstream_remote: str | None
    upstream_sha: str | None
    expansion_version: str | None
    pinned: bool                    # NEW: False when the tree is not a git repo
```

On a directory that is not a git repository, `read_pin` returns:

| Field | Value |
| --- | --- |
| `hack_sha` | `None` |
| `hack_dirty` | `False` |
| `upstream_remote` | `None` |
| `upstream_sha` | `None` |
| `expansion_version` | `"unpinned"` |
| `pinned` | `False` |

It must **not** raise, and must **not** shell out to `git` more than once to discover this.

`pinned` is a separate boolean rather than an inference from `hack_sha is None` because
downstream consumers must not have to re-derive it. **M1-T23** will refuse to write a lockfile
claiming reproducibility when `pinned is False`; record that expectation now.

`rom_probe.py` still must not import `npc_planner.environment`.

### 3. `preprocess_rom.py` narrows its preflight

```python
# scripts/preprocess_rom.py
# Preflight: run_checks(repo, PREPROCESS_REQUIRED)
#
# Exit 0: preprocessing succeeded.
# Exit 2: repo could not be resolved (RomRepoNotFoundError).
# Exit 3: a PREPROCESS_REQUIRED check failed. Print each failing check name and
#         its remedy. Write nothing: no .i files, and do not create <output>.
#
# A non-git tree is NOT an error here. Emit one warning line to stderr containing
# the word "unpinned", and record "pinned": false in ROM_MANIFEST.json.
```

`ROM_MANIFEST.json` gains a top-level `"pinned": bool`. Every other key keeps its current shape.

### 4. Replace the vacuous single-resolver guard

The guard shipped in `M1-T08b` asserted `not hasattr(config, "resolve_rom_repo")`. The duplicate
that actually existed was named `get_rom_repo_path`, so the guard would have passed *before* the
fix. It never guarded anything.

Replace it with a source-text assertion over `src/npc_planner/config.py`:

```python
FORBIDDEN_IN_CONFIG = (
    "NPC_PLANNER_ROM_REPO",
    "pokeemerald-expansion",
    "get_rom_repo_path",
    "resolve_rom_repo",
)
```

Read the file as text and assert none of these appear. Name-based `hasattr` checks cannot catch
a resolver re-added under a new name; the environment-variable literal and the sibling-directory
literal can only plausibly appear in a resolver.

### 5. Acceptance harness

Create `scripts/accept/_lib.sh`, sourced by every future acceptance script:

```bash
# scripts/accept/_lib.sh
# Provides: expect_exit <want> <label> <cmd...>
#           expect_stdout <substring> <label> <cmd...>
#           accept_summary        -> exits 0 if all checks passed, 1 otherwise
#
# Deliberately does NOT `set -e`: several assertions expect non-zero exits.
# Uses `set -uo pipefail` only.
```

`expect_exit` must capture the real exit code of the command it wraps, print
`PASS`/`FAIL <label> want=<n> got=<n>`, and increment a failure counter. `accept_summary` prints
the totals and returns the process exit code. No assertion may be expressed as a shell `&&`
chain.

## Must-pass tests

1. `set(PREPROCESS_REQUIRED) <= set(CHECK_SEVERITY)` and `set(PINNING_REQUIRED) <=
   set(CHECK_SEVERITY)`.
2. Every name in `PREPROCESS_REQUIRED` and `PINNING_REQUIRED` has severity `hard` in
   `CHECK_SEVERITY`.
3. `"is_git_repo" not in PREPROCESS_REQUIRED` - asserted explicitly, because this is the exact
   regression being fixed and it must fail loudly if someone re-adds it.
4. `run_checks(p, ["cpp"])` returns exactly one result, named `cpp`.
5. `run_checks(p, ["nonexistent_check"])` raises `KeyError`.
6. `run_all(p)` and `run_checks(p, tuple(CHECK_SEVERITY))` return equal result lists.
7. `read_pin(tmp_path)` on a plain non-git directory returns `pinned is False`,
   `hack_sha is None`, `hack_dirty is False`, `expansion_version == "unpinned"`, and does not
   raise.
8. `read_pin(git_fake_rom)` returns `pinned is True` and a 40-character `hack_sha`.
9. `read_pin(git_fake_rom_dirty)` returns `hack_dirty is True` and `pinned is True`.
10. `preprocess_rom.py --repo tests/fixtures/fake_rom --output <tmp>` **succeeds** (exit 0),
    emits `.i` files, and writes `ROM_MANIFEST.json` with `"pinned": false`. This is the
    `M1-T08` behaviour that `M1-T08b` broke.
11. The same invocation writes a stderr line containing `unpinned`.
12. `preprocess_rom.py` against a git repo with no `EXPANSION_MARKERS` exits 3, and the output
    directory is not created.
13. `preprocess_rom.py` against a tree that exists and has markers but with `--cpp
    definitely-not-a-real-binary` exits 3.
14. `src/npc_planner/config.py` source text contains none of `FORBIDDEN_IN_CONFIG`.
15. `rom_probe.py` does not import `npc_planner.environment` - assert by reading the module
    source, not by `sys.modules` inspection.
16. `bash -n scripts/accept/M1-T08c.sh` and `bash -n scripts/accept/_lib.sh` both exit 0, run as
    a unit test so a syntactically broken acceptance script fails `make check`.
