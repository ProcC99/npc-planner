# M1-T07 — Author m1_tiny 10-species fixture dataset

## Goal

Create offline test fixture dataset in `tests/fixtures/m1_tiny/` containing 10 species, forms, moves, abilities, type matchups, and metadata. This fixture allows testing baseline load, schema population, and CLI commands completely offline in M1 without network dependencies.

## Files you may create or modify

- `tests/fixtures/m1_tiny/meta.json`
- `tests/fixtures/m1_tiny/species.json`
- `tests/fixtures/m1_tiny/forms.json`
- `tests/fixtures/m1_tiny/moves.json`
- `tests/fixtures/m1_tiny/abilities.json`
- `tests/fixtures/m1_tiny/type_matchups.json`
- `tests/unit/test_m1_tiny_fixture.py`

## Files you may read but NOT modify

- `src/npc_planner/db/schema.sql`
- `docs/schema_manifest.txt`

## Files you may NOT touch

Everything else. Verify with `git diff --name-only` before committing.

## Must-pass tests

1. All 6 fixture files exist and parse as valid JSON.
2. `species.json` contains exactly 10 species.
3. `forms.json` contains at least 10 forms matching the species (including `skarmory`).
4. `moves.json`, `abilities.json`, and `type_matchups.json` contain valid structural records matching staging schema.

## Out of scope — do NOT implement

- Baseline dump fetcher script — that is **M1-T08**
- Ingestion engine — that is **M1-T09**

## Acceptance command

```bash
make check && python3 -c "
import json
from pathlib import Path
p = Path('tests/fixtures/m1_tiny')
species = json.loads((p / 'species.json').read_text())
forms = json.loads((p / 'forms.json').read_text())
print(len(species), len(forms))
"
# expected output: 10 10
```
