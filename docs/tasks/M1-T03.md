# M1-T03 — SQLite DDL for 26 domain tables

## Goal

Create `src/npc_planner/db/schema.sql` containing DDL for all 26 domain tables specified in Section 6 of the system design document.

## Files you may create or modify

- `src/npc_planner/db/schema.sql`
- `tests/unit/test_schema_ddl.py`

## Files you may read but NOT modify

- `docs/schema_manifest.txt`
- `scripts/check_schema_manifest.py`

## Files you may NOT touch

Everything else. Verify with `git diff --name-only` before committing.

## Must-pass tests

1. `schema.sql` executes without error against an in-memory SQLite database (`sqlite3.connect(":memory:")`).
2. All 26 domain tables exist in sqlite_master.
3. `PRAGMA foreign_keys = ON;` and `PRAGMA journal_mode = WAL;` are present at top of `schema.sql`.

## Out of scope — do NOT implement

- 5 staging tables (`stg_*`) & views (`v_form_full`, `v_battle_confidence`) — that is **M1-T04**
- Python session connection factory — that is **M1-T05**
- Pydantic models — that is **M1-T06**

## Acceptance command

```bash
make check && python3 -c "
import sqlite3
from pathlib import Path
conn = sqlite3.connect(':memory:')
sql = Path('src/npc_planner/db/schema.sql').read_text()
conn.executescript(sql)
tables = [r[0] for r in conn.execute(\"SELECT name FROM sqlite_master WHERE type='table'\").fetchall()]
print(len(tables))
"
# expected output: 26
```
