## Part B - the coverage guard must read the source, not the output

`audit_species_coverage(records)` can only see `unparsed_fields`. A key the
parser drops without recording never reaches it, so `uncovered=()` currently
means nothing. This is the T10 guard-swallow defect repeated, and it is mine.

**B1.** New signature:

```python
def audit_species_coverage(
    text: str, records: Sequence[SpeciesRecord]
) -> tuple[str, ...]:
    """Every `.identifier =` key appearing inside gSpeciesInfo[] in `text`
    that is not in MAPPED_FIELDS, not in IGNORED_FIELDS, and not recorded in
    any record's unparsed_fields. Empty means genuinely total coverage."""
```

**B2.** `MAPPED_FIELDS: frozenset[str]` is a **declared constant** listing the
initializer keys the parser handles. It must not be derived from the parser's
behaviour at runtime - a set built by asking the parser what it handled would
agree with the parser by construction, which is the same circularity again. A
test asserts every name in `MAPPED_FIELDS` is actually consumed, and that the
parser consumes nothing outside it.

**B3.** The detects-test plants `.someUnknownRomField = 123` into a **synthetic
header string** and asserts it surfaces. Planting into a record proves only
that the function can read a tuple.

**B4.** `read_species` returns records; a companion
`read_species_with_source(layout) -> tuple[str, tuple[SpeciesRecord, ...]]`
gives callers the text needed to audit. Keep the pure `parse_species(text, ...)`
entry point unchanged.

## Part C - stop discarding required schema columns

`IGNORED_FIELDS = {speciesName, natDexNum}` discards two columns the species
schema requires. The ignore mechanism was specified for sprite pointers,
footprint data and cry ids; it was used on day one to silence required data.

**C1.** Add to `SpeciesRecord`:

- `species_name: str` - from `.speciesName`, unwrapping the `_("...")`
  translation macro. If the literal is absent or empty, raise
  `SpeciesParseError`; do not substitute the `SPECIES_` id.
- `national_dex: int | None` - from `.natDexNum`. If the value is an integer,
  store it. If it is a symbol such as `NATIONAL_DEX_SKARMORY`, store `None` and
  record the symbol in `unparsed_fields`; **do not** guess a number from the
  name.

**C2.** `IGNORED_FIELDS = frozenset()`. Keep the constant and its pin test - the
mechanism is fine, its first use was not. Any future addition needs a comment
naming the field and why it carries no battle-relevant data.

**C3.** State plainly in your report whether the fixture's `.natDexNum` is a
literal or a symbol, and which branch was taken.
