## Must-pass tests

1. `resolve_rom_repo(explicit=p)` returns `p` when it exists, ignoring env and config.
2. Env var wins over config file; config file wins over the sibling convention.
3. All four candidates absent raises `RomRepoNotFoundError`, and the message contains all four attempted paths.
4. `check_expansion_markers` returns `ok=True` on `tests/fixtures/fake_rom/` and `ok=False` on a tmp tree containing only vanilla-pokeemerald paths.
5. `check_upstream_remote` on a git fixture with no remotes returns `ok=False`, `severity="soft"`, and a non-None `remedy` containing `git remote add upstream`.
6. `check_cpp("definitely-not-a-real-binary")` returns `ok=False` rather than raising.
7. `run_all` on a completely empty directory returns a list where every hard check has `ok=False`, and the call does not raise.
8. `scripts/doctor.py --repo <empty tmp dir>` exits 1; `--repo tests/fixtures/fake_rom` exits 0.
9. No network access - socket monkeypatch fixture, same as M1-T08.
